# Codigos Criados em C
São codigos criados em na linguagen C e C++ durandte a minha graduação na Univercidade Federal de Mato Grosso do Sul (UFMS).

## Topicos

* Arvores: Estudo focado em criar e manipular estruturas de dados em formato de arvores.
* Compiladores: Focado na criação de um compilador.
* Monitoria: Codigos/problemas criados para monitoria de Algoritimos e Programação 2.
* Pessoal: São codigos feitos por curiosidade.
* Programação Paralela: Contem codigos voltados para programaçao paralela com OpenMP.
* Refinamento C++: É o refinamento sobre o apredisado de C++, focado em generalização.

OBS: Os topicos tem proprios README para melhores explicações.
